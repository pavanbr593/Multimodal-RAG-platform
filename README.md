## 🌟 Overview

**ContextIQ** is an advanced **AI Knowledge Intelligence Platform** that lets users upload **documents (PDFs)** and **images**, then ask **natural-language questions** and receive **grounded, context-aware answers** — powered by **multi-modal RAG**, **vector search**, and a **local Large Language Model**.

The entire system runs **100% locally** — no OpenAI keys, no paid APIs, no data leaving your machine — demonstrating real-world AI system design patterns used in modern production environments.

## 🧬 AI Techniques Used

### 🔹 Retrieval-Augmented Generation (RAG)
- Retrieves relevant chunks from documents and images
- Injects them into the LLM prompt
- Prevents hallucinations
- Produces grounded, accurate answers

### 🔹 Multi-Modal Embeddings
- **Text embeddings** → SentenceTransformers
- **Image embeddings** → CLIP
- Enables cross-modal reasoning (text ↔ images)

### 🔹 Local LLM Inference
- Uses **Phi-3** via **Ollama**
- Zero cloud dependency
- Low latency
- Data never leaves the system
